# Digital Commerce Performance Analytics

A production-oriented analytics project that transforms raw GA4 ecommerce event data into tested, documented, and business-ready models for acquisition, customer journey, conversion, and revenue analysis.

## Project Status

Project foundation and environment configuration are in progress.

## Planned Architecture

GA4 public ecommerce data  
→ BigQuery raw source  
→ dbt transformation layer  
→ tested analytics warehouse  
→ BI serving layer  
→ Power BI semantic model and dashboards

## Technology Stack

- Google BigQuery
- dbt Core
- SQL
- Python
- Git and GitHub
- VS Code
- Power BI
